# 美术方向（Art Direction）

> 依据：`images/` 下的五张设计稿。本文是可执行的规范，不是灵感板。
> 色值均由设计稿像素实测得出，不是估算。

## 1. 一句话基调

**海洋蓝 × 纯净白 × 科技青**：可爱、治愈、清澈的浮空群岛，配深色科技描边 UI。
情绪是「好奇 + 温柔 + 冒险」，不是硬核或暗黑。

## 2. 调色板（实测）

| 角色 | 色值 | 来源 | 用途 |
|---|---|---|---|
| 深海底色 | `#00162B` | 设计稿主背景 10.9% | 页面 / 场景底 |
| 更深底色 | `#000E22` | 设计稿主背景 9.5% | 阴影、遮罩 |
| 海洋蓝（主色） | `#216BAB` | 场景主色 15.0% | 主体块面、标题 |
| 海洋蓝（深） | `#2D6096` | 角色图 11.2% | 层次、压暗 |
| 星光蓝 | `#79B4E6` | 场景 13.5% | 高光、发光边缘 |
| 科技青 | `#61CDF4` | UI 描边采样 | 交互高亮、边框、能量线 |
| 纯白 | `#F2F4F9` | 角色白 12.8% | 角色主体、正文文字 |
| 深海紫 | `#6B63B2` | 皮肤与特效 | 稀有度、魔法感 |
| 珊瑚粉 | `#E99BA6` | 奶油/珊瑚皮肤 | 强调、皮肤变体、爱心 |

使用比例建议 **60 深海底 : 30 蓝白主体 : 10 青色高光**。青色只用于「可交互 / 有能量」的地方，
不要用来铺大面积背景，否则高级感立刻消失。

## 3. 主角

- **身份**：DeepSeek 鲸灵 / 规则造物师·小鲸
- **形态**：Q 版大头身（约 1:1.4），白色长发渐变到海洋蓝发梢，鲸鱼帽兜带发光圆点，
  白色科技外套 + 深色内衬，蓝色短靴，胸前发光核心。
- **性格关键词**：好奇、聪明、勇敢、温柔、喜欢探索与创造。
- **核心能力**：把想法变成游戏规则 —— 动画上表现为「召唤光点 → 凝结成规则卡片」。
- **伙伴**：小鲸（白色浮游鲸，可跟随、可互动），用作出现在角色旁的情绪反馈。

### 必需动画状态（按设计稿「动作设计」）

`idle` · `run` · `jump` · `fall` · `gravity-flip` · `hurt`
其中 `gravity-flip` 是本作签名动作，必须是可读的翻转姿态，不能复用 `jump`。

### 表情与皮肤

表情：`happy` `wink` `surprised` `thinking` `shout` `sad`（用于 HUD 头像与对话）
皮肤四套：**Ocean 深海探索**（默认）/ **Starry 星空幻梦** / **Coral 珊瑚甜心** / **Night 暗夜程序**。
皮肤只换配色，不换轮廓与动作，这样动画只需一套。

## 5. 关卡元素（来自设计稿清单）

- **敌人**：V1.1 只需要 3 个 —— 泡泡无人机（飞行）、机械蟹兵（地面巡逻）、刺壳浮球（接触伤害）。
  其余 13 种登记为后续素材，不实现。
- **收集物**：金币（基础）、水晶（强化）、星星（稀有）、爱心（回复）、盾（临时防护）。
- **平台**：固定 / 移动 / 云朵 / 弹簧 / 升降 / 可坍塌（对应 `platform.collapseAfter`）。
- **陷阱**：地刺、落石（V1.1 只做这两个，其余不实现）。

## 6. UI 语言

深色玻璃面板 + 1px 科技青描边 + 12～16px 圆角 + 轻微外发光。
信息层级：血条在左上、货币与计时在右上、小地图右上角、关卡目标在右侧面板。

**关键原则**：规则输入框是一等公民。玩家第一眼必须看到「输入一句话」这件事，
而不是先看到玩法按钮 —— 这是产品承诺，也决定了首屏布局。

规则卡片 = 一条规则一张卡，卡片上必须直接写自然语言（如「每跳一次，重力反转」），
而不是写 `player.gravity.toggle`。技术语言只出现在调试视图。

## 7. 素材落地（当前状态）

设计稿不能直接用。要变成 Phaser 素材，需要：

1. 从 `01-character-design.png` 切出角色，去背为透明 PNG，按状态拆帧。
2. 从 `03-enemies-items-props.png` 切出敌人与道具，统一到同一像素密度。
3. 场景素材做九宫格切片，避免拉伸变形。

**在这些素材到位之前，代码里使用运行时生成的占位图形，但色值必须取自本文件第 2 节。**
这样占位版本在美术上已经是对的方向，替换素材时不需要重做布局。
